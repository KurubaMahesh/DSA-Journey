## 5. Problem-Solving Method

For every problem:

1. Understand the problem.
2. Identify the input and output.
3. Check the constraints.
4. Understand the examples.
5. Think of a Brute Force solution.
6. Analyze the Brute Force complexity.
7. Identify the bottleneck.
8. Find the appropriate technique or data structure.
9. Develop a Better solution.
10. Develop the Optimal solution.
11. Implement the solution in C++.
12. Test normal and edge cases.
13. Analyze time complexity.
14. Analyze space complexity.
15. Explain the solution clearly.
16. Record mistakes and important observations.
17. Re-solve the problem later without looking at the solution.

## 7. Complexity Mastery

For every solution, understand:

- Time Complexity
- Space Complexity
- Best Case
- Average Case
- Worst Case
- Auxiliary Space
- Trade-offs between solutions

Important complexities to recognize:

- O(1)
- O(log n)
- O(n)
- O(n log n)
- O(n²)
- O(2ⁿ)
- O(n!)

## Target

Master Arrays to an interview-ready level.

By completing this phase, I should be able to:

- Understand array concepts deeply rather than memorize solutions.
- Implement common array operations in C++ from scratch.
- Identify the correct problem-solving technique from a problem statement.
- Solve array problems from Easy to Medium and selected Hard levels.
- Apply Two Pointers, Sliding Window, Prefix Sum, Hashing, Binary Search, Sorting, and other array techniques confidently.
- Analyze time and space complexity for every solution.
- Develop Brute Force → Better → Optimal problem-solving skills.
- Handle edge cases and large input constraints.
- Solve unfamiliar array problems independently.
- Explain my approach, correctness, and complexity clearly in a technical interview.
- Perform well in college coding assessments and online coding rounds.
- Build a strong foundation for advanced DSA topics and high-level technical interviews.
